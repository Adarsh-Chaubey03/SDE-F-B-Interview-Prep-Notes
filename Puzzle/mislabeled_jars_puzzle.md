# Mislabeled Jars Puzzle

## Question

There are 3 jars labeled:

-   Apples
-   Oranges
-   Apples + Oranges

**Every label is wrong.**

You may pick **only one fruit from one jar**.

How can you determine the contents of all three jars?

## Hint

Pick from the jar labeled **Apples + Oranges**.

## Full Solution

Because every label is wrong, the jar labeled **Apples + Oranges**
cannot contain both fruits.

So it must contain **only apples** or **only oranges**.

### Example: You pick an apple

Therefore:

-   **Apples + Oranges label → Apples only**
-   **Oranges label → Apples + Oranges**
-   **Apples label → Oranges only**

No second pick is needed.

### Key Insight

The jar labeled **Apples + Oranges** gives the most information because
its contents must be a **single fruit type**.
