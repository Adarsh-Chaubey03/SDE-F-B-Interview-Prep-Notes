# Interview Preparation Hub

A structured interview-preparation repository covering the most important concepts, questions, and problem-solving patterns required for **software engineering interviews**.

The goal is to keep concepts, coding problems, SQL queries, and interview questions organized in one place for **revision and interview-specific preparation**.

```text

├── JavaScript/

├── Other Frontend Question/
```

## 🎯 Topics Covered

* **DSA** — Arrays, Strings, Linked Lists, Stacks, Queues, Trees, Graphs, DP, and important interview patterns
* **Backend** — Node.js, Express.js, REST APIs, Authentication, Databases, Scaling, Caching, and System Design basics
* **JavaScript** — Core concepts, ES6+, Asynchronous JavaScript, Promises, Closures, Event Loop, and interview questions
* **React.js** — Components, Hooks, State Management, Rendering, Performance, and common interview questions
* **Frontend** — HTML, CSS, browser concepts, web fundamentals, and frontend interview questions
* **SQL** — Queries, Joins, Subqueries, Aggregations, Window Functions, and interview problems
* **Core CS** — OOP, DBMS, Operating Systems, Computer Networks, and other fundamentals
* **Projects** — Project-specific technical questions, architecture, decisions, and implementation details

## 🚀 Purpose

This repository serves as a **single revision hub for technical interviews**, combining theory, practical questions, coding problems, and SQL practice in an organized structure.

> **Learn → Practice → Revise → Interview**
